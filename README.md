# Smart Visitor Management System

## Project Overview

The Smart Visitor Management System (SVMS) is a custom ServiceNow application developed to automate and simplify visitor management in organizations.

The application enables visitor registration, host approval, security verification, visitor check-in/check-out, notifications, reporting, and dashboards.

This project is being developed as part of my ServiceNow CSA and CAD interview preparation to gain practical experience with the Now Platform.

---

- Learn ServiceNow Application Development
- Build a real-world enterprise application
