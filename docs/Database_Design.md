# Database Design

## Visitor Table

The Visitor table is the primary table of the Smart Visitor Management System.

## Table Details

| Property | Value |
|----------|-------|
| Table Label | Visitor |
| Table Name | visitor |
| Auto Number | Enabled |
| Prefix | VIS |
| Starting Number | 1000 |
| Extensible | No |

## Purpose

The Visitor table stores all visitor-related information, including registration details, approval status, and visit tracking.

More fields will be added during Day 2.
